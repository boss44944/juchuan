# 菊传 (Juchuan)

一个无需安装手机 App、无需账号、无需云服务的局域网文件与剪贴板传输工具。

电脑运行菊传后，手机只需要打开浏览器，即可在同一个局域网内完成：

- 文件传输
- 图片传输
- 文字传输
- 剪贴板共享

所有数据都只在你的局域网内流转。

---

## 为什么叫「菊传」

「菊传」是「局传」的谐音。

这里的「局」来自「局域网」。

名字只是为了简单、好记、有传播性，让大家一看到名字就能联想到：

> 在局域网里传东西。

---

## 项目背景

日常使用电脑和手机时，经常会遇到：

- 手机照片需要传到电脑
- 电脑文件需要发送到手机
- 手机复制的一段文字需要同步到电脑
- 电脑上的链接需要快速在手机打开

传统方式通常依赖：

- 微信文件传输助手
- QQ
- 网盘
- 邮件
- 数据线

这些方式通常存在：

- 需要账号
- 依赖互联网
- 文件经过第三方服务器
- 大文件传输速度受限制

菊传希望提供一个更简单的方案：

> 打开电脑，手机浏览器直接访问，马上开始传输。

# 核心功能

## 文件传输

支持任意文件类型：

- 图片
- 视频
- PDF
- 压缩包
- 文档
- 程序文件
- 其他任意格式

不会限制文件扩展名。

---

## 文件自动管理

上传文件不会全部堆积在一个目录。

按照日期自动分类：

```
uploads/

├── 2026-07-27/
│   ├── photo.jpg
│   ├── document.pdf
│   └── archive.zip
│
└── 2026-07-28/
    └── image.png
```

优点：

- 降低文件重名概率
- 按日期快速查找
- 适合长期运行

---

## 文件重名处理

不会修改原文件名。

如果存在同名文件，会自动追加编号：

```
photo.jpg
photo(1).jpg
photo(2).jpg
```

保持原文件名称习惯，方便后续查找和使用。

---

## 文字与剪贴板传输

支持电脑和手机之间发送文字：

- 普通文本
- 链接
- 代码
- 临时内容

数据库只保存文字历史。

文件和图片不会存入数据库。

---

# 设计原则

## 本地优先

菊传不依赖云服务器。

数据路径：

```
手机
  |
  | 局域网
  |
电脑上的菊传
```

所有文件直接保存到你的电脑。

---

## 数据库轻量化

数据库只保存：

- 文字内容
- 文件记录
- 文件路径
- 历史信息

不会保存：

- 图片二进制
- 文件内容

避免数据库随着文件增长而膨胀。

# 技术架构

使用 Go 开发。

目标：

- 轻量
- 高性能
- 少依赖

架构：

```
手机浏览器
      |
      |
 HTTP/WebSocket
      |
      |
  Juchuan Server
      |
      +----------------+
      |                |
 文件系统          SQLite
```

当前仓库采用前后端分离目录：

```
juchuan/
  backend/   # Go 服务端
  frontend/  # Vue3 + Vite 前端
  static/    # 兼容旧版静态页面
```

---

# 本地开发

## 启动后端

```bash
cd backend
go run .
```

## 构建后端

```bash
cd backend
go build ./...
```

## 启动前端开发服务

```bash
cd frontend
npm install
npm run dev
```

前端开发代理默认转发到 `http://localhost:8000`。

## 前端构建并由 Go 服务托管

```bash
cd frontend
npm run build

cd ../backend
go run .
```

构建后，Go 服务优先托管 `frontend/dist`；如果 dist 不存在，会回退到 `static/` 兼容页面。
